
# Freight Rate Prediction — Spotter ML Assessment

## Objective

Develop a supervised machine learning model to predict
freight shipment rates from shipment and market features.

## Approach

1. Explore and validate the supplied data.
2. Clean data and engineer relevant features.
3. Design an appropriate validation strategy.
4. Compare baseline and machine learning models.
5. Generate predictions for the unseen validation set.
6. Validate the deliverables using the provided scorer.
